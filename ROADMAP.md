# Roadmap

This roadmap describes planned work. It does not promise a release date or a
fixed implementation. Use [Issues](https://github.com/EurekaRBLX/easyRoad/issues)
to discuss a proposal.

## Open-source preparation

- Confirm the rights to release project code and included assets.
- Complete third-party license and attribution review.
- Review repository content and history before public access.
- Validate the AGPL plugin builds and public documentation.
- Establish release, contribution, and private security reporting procedures.

The repository remains private during this work.

## Intersection controls and crossings

- Stop and give-way markings for individual junction approaches.
- Pedestrian and cycle crossings.
- Regional crossing markings, including optional zig-zag lines.
- Signal attachment points and basic signal controls.
- Lane guidance, turn arrows, and junction surface markings.

## Roads and structures

- Undoable terrain excavation and restoration for tunnels.
- Custom portal, abutment, and pier assets.
- Combined bus bays and road profile transitions.
- Kerb-restriction markings that follow a bus bay.
- Further texture and MaterialVariant support.

## Performance and validation

- Repeatable Studio benchmarks for build time, preview time, and part counts.
- Further reduction of generated parts while preserving geometry and editing.
- Broader Luau analysis and runtime checks.
- More Studio validation of road seams, collision, and roundabout connections.

See [KNOWN_ISSUES.md](KNOWN_ISSUES.md) for current limitations.
