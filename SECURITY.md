# Security policy

## Report a vulnerability privately

Do not post vulnerability details, credentials, or an exploit in a public issue
or pull request.

1. Open the repository's **Security** tab.
2. Use **Report a vulnerability** if private reporting is enabled.
3. If that option is unavailable, ask a Eureka maintainer for a private channel
   through the [Eureka Discord](https://discord.gg/srGUZ25jrz).
4. Share the details only after the maintainer provides a private channel.

Include the affected build, the steps to reproduce the problem, the impact,
and a minimal example. Remove unrelated personal information and private assets.

If a credential is exposed, revoke or rotate it through the service that issued
it. Removing the visible text alone does not revoke the credential.

## Supported builds

The project is in private release preparation. No stable public release or
long-term security support policy has been established. Report problems against
the current default branch and include the commit or build identifier.

The maintainers will assess reports as they receive them. No response time is
promised.
