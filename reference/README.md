# Geometry references

This directory contains selected third-party source files and geometry
research notes. It is outside the plugin build paths. The generated plugin
does not include these reference files.

| Directory or document | Content |
| --- | --- |
| [roadhelper](roadhelper/README.md) | RoadHelper T/X intersections, road segments, and connection calculations. |
| [roadcreator](roadcreator/README.md) | RoadCreator intersection and roundabout mesh algorithms. |
| [Geometry options](INTERSECTION_ROUNDABOUT_OPTIONS.md) | Comparison criteria for future geometry work. |

Each source directory records its upstream project, commit, copyright, and
license. Keep those notices when you copy or adapt code. Also record the
adaptation in the relevant source module and the
[third-party notices](../THIRD_PARTY_NOTICES.md).
